Get started

Install in three steps

Download the ZIP, then use Chrome's built-in extension settings.

  1. 01

    Download the ZIP

    Save the v0.1.0 release file from the button above.

  2. 02

    Extract the files

    Unzip the download to a folder you can find again.

  3. 03

    Load the extension

    Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the extracted extension/ folder.
